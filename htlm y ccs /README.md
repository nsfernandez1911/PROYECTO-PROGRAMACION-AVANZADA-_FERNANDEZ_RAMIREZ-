# PROYECTO_FERNANDEZ_RAMIREZ

## 📘 Proyecto — Desarrollo Web

Repositorio desarrollado por **Juan Diego Ramírez** y **Nicolás Fernández** como parte de la asignatura **Programación Avanzada** de la **Corporación Universitaria del Huila (CORHUILA)**.

---

## 🧩 Descripción

Este proyecto tiene como objetivo desarrollar una página web aplicando los conocimientos adquiridos durante el **primer corte de Programación Avanzada**.

Durante esta etapa se trabajan los fundamentos del desarrollo web mediante **HTML, CSS y JavaScript**, permitiendo construir una aplicación web con una estructura organizada, una interfaz visual y elementos interactivos.

El proyecto busca poner en práctica conceptos relacionados con:

- Estructura de páginas web.
- Etiquetas y elementos HTML.
- Diseño y estilos mediante CSS.
- Interactividad mediante JavaScript.
- Organización de archivos de un proyecto web.
- Integración de HTML, CSS y JavaScript.
- Buenas prácticas básicas de desarrollo.

---

## 🎯 Objetivos

### Objetivo general

Desarrollar una aplicación web utilizando **HTML, CSS y JavaScript**, aplicando los conocimientos adquiridos durante el primer corte de la asignatura Programación Avanzada.

### Objetivos específicos

- Crear la estructura de una página web utilizando HTML.
- Aplicar estilos y diseños mediante CSS.
- Incorporar funcionalidades e interactividad utilizando JavaScript.
- Organizar correctamente los archivos del proyecto.
- Comprender la relación entre HTML, CSS y JavaScript.
- Implementar una interfaz sencilla, funcional y fácil de utilizar.
- Aplicar buenas prácticas básicas de programación y desarrollo web.

## 🚀 Características principales

### 📄 HTML

La aplicación utiliza HTML5 para organizar el contenido mediante:

- Encabezados.
- Párrafos.
- Imágenes.
- Enlaces.
- Listas.
- Formularios.
- Botones.
- Secciones.

### 🎨 CSS

CSS se utiliza para mejorar la apariencia visual de la página:

- Colores.
- Tipografías.
- Tamaños.
- Márgenes.
- Padding.
- Bordes.
- Fondos.
- Botones.
- Distribución de elementos.

### ⚙️ JavaScript

JavaScript permite agregar comportamiento dinámico a la página:

- Variables.
- Funciones.
- Condicionales.
- Eventos.
- Interacción con el usuario.
- Manipulación del DOM.
- Cambios dinámicos en el contenido.
