# Portafolio Examen Final

Proyecto de universidad: portafolios personales en HTML + CSS + Bootstrap.

Cada estudiante tiene su propia carpeta independiente, con su propio `index.html`, `style.css` y `README.md`. Cada carpeta corre por separado (no dependen la una de la otra).

## Estructura

```
PORTAFOLIO EXAMEN FINAL/
├── README.md              <- este archivo
├── nicolas/
│   ├── index.html
│   ├── style.css
│   └── README.md
└── juandiego/
    ├── index.html
    ├── style.css
    └── README.md
```

## Cómo ejecutarlo en Visual Studio Code

1. Abre la carpeta `PORTAFOLIO EXAMEN FINAL` completa en Visual Studio Code (`File > Open Folder`).
2. Entra a la carpeta de la persona que quieras ver (`nicolas` o `juandiego`).
3. Click derecho sobre `index.html` → **Open with Live Server** (si tienes la extensión "Live Server" instalada).
   - Si no la tienes: ve a la pestaña de Extensiones (ícono de cuadritos a la izquierda), busca **Live Server** de Ritwick Dey, instálala.
4. Se abrirá el navegador mostrando el portafolio.

También puedes simplemente hacer doble clic en el `index.html` de cada carpeta y se abrirá en el navegador, sin necesidad de Live Server.
